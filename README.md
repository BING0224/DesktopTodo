# DesktopTodo v0.3.0

一个轻量的 Windows 桌面待办组件。原生 Win32 实现，不需要登录；待办和设置保存在本机。本版新增右侧停靠：需要查看任务时展开面板，平时收起为贴在桌面右缘的小图标。

## 下载与运行

适用于 **Windows 10/11 x64**。在 [Releases](https://github.com/BING0224/DesktopTodo/releases) 下载 **v0.3.0** 的 `DesktopTodo.exe`，放到固定位置后双击运行。发布版静态链接 C++ 运行库，运行时无需安装 Visual Studio 或 .NET。GitHub 自动生成的 *Source code (zip)* 是源码；直接运行请下载 Release 附件中的 EXE。

如果移动 EXE，已开启开机自启的用户应在设置中关闭后重新开启一次，使启动路径指向新位置。

## v0.3.0 更新

- **右侧停靠：** 点击面板顶部的收起按钮，桌面右边缘只留下蓝绿渐变待办图标；单击图标重新展开完整面板。图标可沿右边缘上下拖动并记住位置。
- **数量角标：** 图标左上角显示未完成待办数；没有未完成待办时隐藏，超过 99 项显示 `99+`。
- **启动方式：** 通过开机自启启动时默认处于停靠状态；手动打开时恢复上次的展开或停靠状态。旧版的待办与设置文件继续使用，新增停靠位置字段不会清除旧设置。
- **多显示器：** 记录停靠所在的显示器和相对高度；显示器或工作区域变化后，将图标保持在可见范围内。

## 主要功能

- 添加、勾选完成、双击原位编辑和删除待办；支持多行文字。删除待办或移除资源前会显示确认弹窗。
- 可设置截止日期、时间或“当天内”，列表按逾期、未到期、长期和已完成排序；临近截止和逾期显示不同颜色。
- 待办可关联文件、文件夹和网址。点击文件名可在资源管理器中定位文件；点击文件夹名打开目录；点击网址在默认浏览器中打开。关联仅保存路径或网址，不会复制文件。
- 蓝白半透明圆角面板支持自由拖动、缩放和滚动；不出现在任务栏和 Alt+Tab 列表。设置菜单包含开机自启、打开数据文件夹及恢复默认窗口。

## 数据与升级

数据位于 `%LocalAppData%\DesktopTodo\`。从 v0.2.0 升级时，先退出旧程序，再运行新版 EXE；`todos.json` 和 `settings.json` 会继续使用。建议升级前复制整个数据文件夹作为备份。请勿同时运行 v0.1.0 WPF 版与新版，否则旧程序保存数据时可能丢弃新字段。

## 从源码构建

安装 Visual Studio 2022 的“使用 C++ 的桌面开发”组件和 Windows SDK，解压源码后在项目根目录运行 `build.cmd`。它会生成 `build\DesktopTodo.exe`；`run.cmd` 会构建后运行，`publish-win-x64.cmd` 会复制 EXE 到 `publish\win-x64\DesktopTodo.exe`。程序采用 C++17、Win32 和 GDI+，编译时通过 `/MT` 静态链接 C++ 运行库。

仓库的 Windows 构建工作流也会上传 EXE 作为构建产物；供普通用户下载的正式版本以 Releases 的附件为准。
